Drawing a new one

Add the points, run the script

Icons are not exported from a drawing app. Each one is a short list of points in scripts/build_icons.py, on a 24px grid. The script roughens the points the same way every time, so the set stays consistent and a diff shows exactly what changed.

  • Keep it to two or three strokes. If a drawing needs more, it is an illustration, not an icon. Check it at 16px before you commit it.
  • One accent stroke per icon, for the part that carries the meaning (the door, the sprout, the rain).
  • Round caps and joins, about 1.9px line at 24px. Never fill a shape with solid ink; the tint is the only fill.
  • Run python3 scripts/build_icons.py and commit the regenerated icons.svg, logo.svg, favicon.svg and this page.

Icons need the sprite file, so they appear when the site is served over HTTP (python3 -m http.server) or on Vercel. They do not load when a page is opened straight from disk, because browsers block external SVG references there. Every icon is decorative and carries aria-hidden; the text beside it names the action.
