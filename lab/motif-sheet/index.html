Ten motifs drawn from reference sheets

Before there was a generator, there was a sheet of ten hand-built vector motifs. This is what each one is made from, how its colors are wired, and a sheet you can randomize.

By Nate AndersonNov. 21, 20265 min read2 sourcesLab 4 of 7

01Where the pattern system started

Before the seeded generator, there was a sheet of ten hand-built SVG motifs. I made it first because I wanted to check that the recipe from the reference library worked as original art before I wrote any code to randomize it. If the static motifs did not look right, a generator would only multiply the problem.

02What each motif is built from

Each one comes from a habit I saw in the references, and each one has a use on the site.

  1. Grid-filled solids and split discs. Draw a shape in its flat color, then draw the same shape again filled with a 10 pixel graph-paper pattern at 70% ink. The grid stays on the shape, never the field. Used for hero art, dividers and stat cards.
  2. Overlapping circles. Three circles at 85% opacity with multiply blending, centers 70 pixels apart. Used for “evidence overlaps” figures.
  3. Set square and protractor. The drafting tool is the illustration: a triangle with a cutout and tick marks, a half disc with ticks every 2 degrees and one brick line as the measured angle.
  4. Contours. Nested wobbly rings, every fifth heavier, the same idea as the contour lines in the survey sheets.2
  5. Halftone. A staggered dot grid whose dot radius falls from one side to the other, for transitions between bands.
  6. Plan symbols. Tree canopies with a center dot, a dashed slate flow line, a scale bar, a north arrow and a double border like a drawing sheet. Moss for trees and slate for water, matching the design system.
  7. Three-tile collage. Two or three tiles side by side, each one thing, each on its own saturated field. This is the layout of the banners.1
  8. Pill diagram. Rounded pill labels joined by hairline arrows with pale fills, for process figures such as Site, Measure, Plan.

03The decisions I made

Wire every color as a CSS variable on the figure

Each motif exposes --field, --a, --b and so on. Randomizing is then one line of script, and the generator that replaced this sheet could reuse the same idea.

CostThe sheet itself uses literal hex values for a few fixed pieces, so it is a lab, not a model of token discipline.

Propose five art accents instead of using only the interface colors

Brick, moss and slate are too serious for decorative tiles; a field of sky, ochre, rose, kelly or periwinkle reads as the playful flat color the references use. They are for decoration only.

CostAdding colors to the system means updating DESIGN.md, which the pattern work did.

Offer drift as a toggle, not a default

Drift adds a slow six-pixel slide and the color transition. It is off until you press it, and it never runs under reduced motion.

CostOn the sheet, motion is opt-in, which hides it from anyone who does not press the button.

Keep the sheet, then build the generator

The ten static motifs proved the look first. The generator in the pattern sheet article took them from fixed files to seeded art.

CostThe two sheets overlap, and the static one is no longer the source of truth.

04The live sheet

Press Randomize colors to swap each motif’s colors from the palette, Reset to go back, and Drift for the slow motion.

05What I could not verify

Limits of this lab

  • The sheet is a design study. Its colors were chosen by eye against the reference sheets, and I did not run contrast checks because the motifs carry no text of meaning.
  • The motifs are original drawings built from patterns that recur across the references, not traced from any one sheet. I list the sources I looked at so the influence is visible.
