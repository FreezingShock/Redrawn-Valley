How this index is made, and its limits

A script (scripts/build_atlas.py) reads every page. Terms are the field guide titles plus a short list I keep, places are a list I keep, and sources and drawings come from each page’s own source list and figure captions. Mentions are found by matching words, so a page that talks about an idea without using its name will be missed, and a name used in a different sense can be listed by mistake. Tell me and I will fix the list.
