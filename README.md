# Redrawn Valley

Seeing the valley anew.

Small places in the San Fernando Valley, studied and redrawn. A static site: no build step, no dependencies.

## Run it

Open `index.html` in a browser. Or serve the folder:

```
python3 -m http.server 8000
```

## Branches and deploys

- `main` is production (Vercel). `integration` is where work lands first (Vercel preview). PRs target `integration` and auto-merge once `scripts/check.py` passes; add the `hold` label to stop one. Promote with Actions > "Promote integration to main", then merge that PR by hand.
- Vercel: framework preset **Other**, no build command, no output directory.

Design rules live in `DESIGN.md` (the Redrawn Design System). Agent rules live in `CLAUDE.md`.

## Structure

```
index.html, 404.html               front page, not-found page (root-absolute paths, served by Vercel)
studies/<slug>/index.html          one study each; studies/_template/ is the starting copy; studies/index.html lists them
guide/<slug>/index.html            Field Guide entries; guide/index.html has search and the topic filter
notes/<slug>/index.html            essays; notes/index.html lists them
lab/<slug>/index.html              lab articles (intro, process, decisions, embedded demo); the demos themselves live at
                                   patterns/, icons/, fonts/ and similar top-level folders
topics/, a-z/, sources/, log/      generated pages (see scripts/ below); log/feed.xml is the Atom feed

assets/rds/                        the Redrawn Design System: every shared stylesheet and script (see DESIGN.md)
  tokens.css                       the one token file; nothing else may hold a colour, size, time or font
  rds.css, skin.css, theme.css     components, responsive + sketchbook layer, dark theme (theme.css is partly generated)
  motifs.js                        seeded generative art; also exports the shared seeded generator (RDSArt.Rng, RDSArt.hash)
  <feature>.css + <feature>.js     one pair per feature: flow, loops, margins, interact, search, rail, tabbar, atlas, log, ...
  icons/                           hand-drawn icon sprite, logo, favicon (generated by scripts/build_icons.py)
assets/site-shell.js               shared header, footer, breadcrumbs and search loader, injected into placeholders
assets/site.css, studies.css/.js   rules and behaviour specific to this site's home page and study pages
assets/*.json                      generated data: search index, sources, log, topics (topics.json is hand-written)
fonts/                             self-hosted font files; fonts/index.html is the type lab
sitemap.xml, robots.txt            generated by scripts/build_index.py
vercel.json                        cache headers (immutable for fingerprinted CSS/JS) and the deploy rule
DESIGN.md, CLAUDE.md               design system write-up, working rules
```

Naming: folders and files are lowercase with hyphens for pages and assets (`ventura-topanga-corner`, `site-shell.js`) and underscores for Python (`build_index.py`). A page folder always holds `index.html`.

## Scripts

Everything in `scripts/` is plain Python 3 with no dependencies. `scripts/common.py` holds the shared bits (repo root, the page list, the `--check` flag).

| Prefix / file | What it does |
|---|---|
| `regen.py` | Runs every generator below in dependency order. `--check` names what is stale and writes nothing. CI runs it after each merge. |
| `check.py` | The PR gate: links, anchors, imports, token check (`check_tokens.py`), and a call to `regen.py --check`. |
| `build_*.py` | Generated pages and data: `build_log`, `build_sources`, `build_index` (search index, sitemap, robots, A-Z page via `build_atlas`), `build_topics`, `build_theme`. One-off tools: `build_icons`, `build_hershey`, `build_type_lab`. |
| `assetver.py` | Stamps `?v=<hash>` on every CSS/JS reference for immutable caching. Last step of `regen.py`. |
| `art_*.py` | Drawing generators that write marked regions into pages: `art_topanga`, `art_fallbrook`, `art_ventura_corner`, `art_guide`, `art_tiles`, `art_home_panels`, with `art_lib.py` as the shared sketch helper. Run by hand after changing a drawing. |
| `data/`, `log_notes.json`, `token-baseline.json` | Inputs: parcel outlines, plain-language log entries, the token check's allowed-leftover counts. |

## Shared shell and search

New pages get the header, footer, breadcrumbs and search by including three placeholders and one script (see `DESIGN.md`, "Shared shell"). After adding or retitling a page run `python3 scripts/build_index.py` and commit the regenerated `assets/search-index.json`, `sitemap.xml` and `robots.txt` (`scripts/check.py` warns when they are stale; if two PRs conflict on them, rerun the script). The sitemap uses the domain in `SITE_URL` at the top of that script.
